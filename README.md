### 🚀 Recent Work

#### 🏦 <a href="https://github.com/moinsarwar/financial-system">Financial System</a> — Comparison Engine monorepo

Pakistan / GCC **comparison + lead-gen platform** ([thecomparisonengine.com](https://thecomparisonengine.com)): savings, cards, loans, insurance ranking, partner white-label resellers, and vertical marketplaces — FastAPI backends, React frontends, PostgreSQL, Docker, nginx, and Ollama (`qwen2.5`) for AI Explain.

| Module | Major work |
|--------|------------|
| **finOS** | Core SoR — product ranking, Cost/Matrix views, eligibility, staff portal (React/Vite), public compare UI, AI Explain over Ollama |
| **Reseller** | Partner signup → admin approve → dashboards, commission webhooks, white-label subdomains |
| **GreenDrivePakistan** | Sharia green marketplace — solar/EV kit, Murabaha BNPL math, vendor/admin/user roles, AI recommend |
| **HomeCompare** | Appliance compare + **running-cost** calculator, JWT dashboard, seeded catalog |
| **AutoCompare** | Car compare, info requests, login-gated test-drive flows, admin follow-up |
| **Drive2Earn** | Vehicle access for gig drivers — affordability estimates, applications, admin ops |
| **qwenChat / adminPortal** | Internal ops chat over live APIs + Docker/finOS admin console |

<code>FastAPI</code> · <code>React</code> · <code>TypeScript</code> · <code>PostgreSQL</code> · <code>Docker</code> · <code>Ollama</code> · <code>nginx</code>
